# Smart File Organizer

A Python automation tool that organizes files into folders based on their extensions.

## Features

- ✅ Organizes files by type (Images, Documents, Videos, Music, Archives, Code)
- ✅ Creates category folders automatically
- ✅ Handles unknown extensions (moves to "Others")
- ✅ Handles files without extensions
- ✅ Handles duplicate filenames (renames automatically)
- ✅ Handles invalid folder paths gracefully
- ✅ Ignores already-organized files

## Technologies Used

- **Python 3.12+**
- **pathlib** for file handling
- **shutil** for moving files
- **Type hints** for clean code
